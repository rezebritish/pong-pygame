# Pong на pygame-ce

Игра Pong, написанная на Python с классами Paddle, Ball и Game.
Ракетки с персонажем C.C., мяч со свечением, градиентный фон.

## Запуск

1. Установи Python 3.13 и библиотеку: `pip install pygame-ce`
2. Запусти файл `main.py`

## Управление

- Стрелки вверх и вниз: двигать правую ракетку
- Левой ракеткой управляет бот

## Сложность бота

В файле `settings.py` меняй `opponent_speed`: 5 лёгкий, 7 средний, 10 сложный.

## Структура

- `main.py`: запуск игры
- `game.py`: класс Game, цикл, счёт
- `ball.py`: класс Ball
- `paddle.py`: класс Paddle
- `settings.py`: настройки
